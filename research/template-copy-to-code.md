### A file is a contract, not just the HTML field

**Read:** the SDK hashes `parseTemplateFile(fileBytes)`: subject is the first title with a limited set of entities decoded and ASCII whitespace collapsed/trimmed; preheader is the first matching meta content with entities decoded; HTML is the entire file; no text part is produced. **Proposal:** one deterministic file encoder must insert/update the authoritative title and preheader in the exported document before any other title/meta candidates, preserve Liquid expressions literally, and return a whole `.html` document.
