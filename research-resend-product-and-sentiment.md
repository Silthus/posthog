# Resend: product, sentiment, switching and agent reach

Ticket: [#527](https://github.com/Silthus/posthog/issues/527). Map: [#461](https://github.com/Silthus/posthog/issues/461).
Sibling research, not repeated here: [#522](https://github.com/Silthus/posthog/issues/522) (send API surface, React rendering, key permissions).
Research date: 2026-10-20.
Author: research sub-agent, Sonnet 5.5.

## How to read this report

- Product facts come from Resend's own docs, pricing page, changelog feed and `llms.txt`. Those are primary sources.
- Sentiment comes from a thin, public sample: Hacker News (Algolia API, read directly), Product Hunt, Resend customer stories, GitHub issues, and vendor or blogger comparisons. Counts below are counts inside that sample, not market shares.
- Reddit and G2 could not be read (see [Evidence gaps](#evidence-gaps)). The sentiment ranking therefore leans on Hacker News and Product Hunt.
- Competitor comparison pages (Postmark, Sequenzy and similar) are marketing. They are marked as vendor claims.
- Every number from a page is as of 2026-10-20 unless a date is given.

## Summary: ranked decision lines

Most loved, by how often it comes up:

1. Fast, simple developer experience: clean API, 9 SDKs, 40-plus framework guides, working in minutes. Product Hunt tags: ["developer-friendly API" 27, "easy setup" 25, "fast integration" 17](https://www.producthunt.com/products/resend/reviews).
2. React Email: 9 Product Hunt mentions; [19.8k GitHub stars](https://github.com/resend/react-email); 4.39M weekly npm downloads for `@react-email/components` (npm API, week of 2026-10-12).
3. No approval, no sandbox, send from day zero: [HN](https://news.ycombinator.com/item?id=45239551) and [Resend KB](https://resend.com/docs/knowledge-base/does-resend-require-production-approval.md).
4. A clean dashboard with logs and event timeline: [Launch HN](https://news.ycombinator.com/item?id=36309120) comments, [Dub](https://resend.com/customers/dub.md), Product Hunt "simple UI" 12.
5. Perceived reliability and deliverability: Product Hunt "reliable delivery" 18, "high deliverability rates" 9. This is polarized; see the complaints.
6. Shipping pace: [113 changelog entries, 54 of them in 2026](https://resend.com/changelog/rss.xml).

Most missing or disliked, ranked by frequency and severity:

1. **Deliverability opacity on shared SES infrastructure.** Highest severity: silent loss of customer mail. [Anukari, Feb 2026](https://anukari.com/blog/devlog/abandoning-resend-com-for-email) reports a cross-account blocklist that ate license-key emails. [2024 delay complaint](https://news.ycombinator.com/item?id=39546077). "SES wrapper" remarks appear in [several HN threads](https://news.ycombinator.com/item?id=39478725).
2. **Price shape.** Free tier capped at 100 per day, a $20 floor, per-domain caps, and a $35 to $90 jump for the same 100k volume. Users compare it to SES and Cloudflare. [HN, Apr 2026](https://news.ycombinator.com/item?id=47793992).
3. **Account pauses on thresholds.** Bounce rate above 4% or complaint rate above 0.08% pauses sending. [Resend limits page](https://resend.com/docs/knowledge-base/account-quotas-and-limits.md). First-person complaint evidence is thin.
4. **No environment separation.** No sandbox, no message streams or servers. [Resend says so itself](https://resend.com/docs/knowledge-base/does-resend-require-production-approval.md); [Postmark attacks it](https://postmarkapp.com/compare/resend-alternative) (vendor claim).
5. **Analytics and person context.** Reviewers want [deeper analytics](https://www.producthunt.com/products/resend/reviews); HN users want mail "aware of what the user has done" ([swyx, 2023](https://news.ycombinator.com/item?id=36312454)).
6. **Packaging friction around React rendering.** Most-reacted GitHub issues are about bundling `react-dom/server`, Next.js and pnpm. All closed.
7. **Fixed API ceiling.** 10 requests per second per team, shared by all keys, not raised by upgrading.

Top switching reasons:

- Into Resend: leaving SendGrid or Postmark for simpler DX and instant start ([Raycast](https://resend.com/customers/raycast.md), [Dub](https://resend.com/customers/dub.md), [Depot on HN](https://news.ycombinator.com/item?id=36311661)).
- Out of Resend: deliverability trust (to Postmark), price at scale or at low volume (to SES, Scaleway TEM, Cloudflare Email Service), and "SES wrapper" skepticism.

PostHog's openings:

1. **Person context in the email.** Resend contacts are a separate list. PostHog templates already read `person.properties` and run inside workflows (`products/workflows/skills/designing-email-templates/SKILL.md`). This is the clearest differentiator.
2. **Price anchor.** Cloudflare lists $0.35 per 1,000 and SES $0.10; Resend overage is $0.90 at Pro. Whether PostHog beats this is not verified here.
3. **Switch tooling for agents.** Resend publishes five migration guides (SendGrid, Postmark, Mailgun, Customer.io, Mailchimp). Nobody publishes an agent skill for leaving Resend (see [#522](https://github.com/Silthus/posthog/issues/522)).
4. **Deliverability is not an opening yet.** PostHog sends through SES too (`products/workflows/backend/providers/ses.py`, `nodejs/src/cdp/services/messaging/helpers/ses.ts`). The "SES wrapper" critique applies unless PostHog adds per-team isolation and visible suppression and reputation data.

### 1.2 Pricing and limits (pricing page, 2026-10-20)

Source: [resend.com/pricing](https://resend.com/pricing), [quotas and limits](https://resend.com/docs/knowledge-base/account-quotas-and-limits.md), [rate limit](https://resend.com/docs/api-reference/rate-limit).

| Plan       | Price per month | Included     | Daily cap | Domains  | Webhook endpoints | Support                           |
| ---------- | --------------- | ------------ | --------- | -------- | ----------------- | --------------------------------- |
| Free       | $0              | 3,000        | 100       | 3        | 1                 | Ticket                            |
| Pro        | $20 / $35       | 50k / 100k   | none      | 10       | 5                 | Ticket                            |
| Scale      | $90 to $1,150   | 100k to 2.5M | none      | 1,000    | 10                | Ticket, Slack channel, urgent SLA |
| Enterprise | Custom          | Custom       | none      | Flexible | Flexible          | CSM, 99.99% SLA                   |

- Overage per 1,000: $0.90 on Pro and the $90 Scale tier, falling to $0.46 at 2.5M. Overage is optional and caps at 5 times the monthly quota.
- Retention: 30 days on Free, Pro and Scale.
- API rate limit: 10 requests per second per team, shared by all keys, same on every plan; raise it only through support. A batch call counts as one request.
- Free daily limit resets at midnight UTC. Received mail counts toward quota. Each To, CC and BCC recipient counts as one email.
- Add-ons: dedicated IP $30 per month (Scale), extra 100 domains $20 per month, SSO $150 per month (Scale), extra inboxes $1 each.
- Marketing: separate contact-based tiers, $0 for 1,000 contacts to $650 for 150,000 contacts. Email volume is not capped. Automations: 10,000 runs a month included, then $0.0015 per run.
- No annual discount. Nonprofits get 50% off.
- Pro at 100k costs $35, Scale at 100k costs $90. The price difference buys domains, Slack support and SLA, not volume.
- Resend's pricing page contradicts itself on dedicated IPs for Enterprise ("included" in the text, "with add-on" in the table).

### 1.4 Reliability record

- [Status page](https://resend-status.com/): 100% uptime across all 13 components for Sep to Oct 2026 (about two months; nothing older read).
- [Security incident, 2024-01-10](https://news.ycombinator.com/item?id=38946157) and [production database drop, 2024-02-21](https://news.ycombinator.com/item?id=39476446). The second thread has 73 points; commenters criticize production access practices, and others praise the open report.
- [Knock benchmark](https://knock.app/email-api-benchmarks) (traffic routed through Knock, 2026-07-21 to 2026-10-19): median API latency Resend 84 ms, Postmark 60 ms, SendGrid 14 ms, SES 163 ms; 5xx rate 0.00% for all. Resend and Postmark sit in the 1M to 10M volume band, so treat as indicative.

### 5.2 What makes an agent pick Resend (inference, not a controlled test)

No test of agent provider choice was run. The reasons below come from Resend's own material plus usage numbers:

1. **Training and docs presence.** `resend` leads npm at 8.13M weekly downloads against 2.56M for SendGrid's mail package, 2.28M for the SES client and 0.64M for Postmark (npm API, 2026-10-12 to 2026-10-18). An agent asked to "send an email" in a JS project sees Resend most.
2. **Zero-friction start.** No approval and no sandbox; a human still must sign up and create the key ([AI onboarding](https://resend.com/docs/ai-onboarding.md)). Resend's own post argues the same: "Agents are simply not going to 'contact sales'".
3. **Everything machine-readable at one URL.** `llms.txt`, `.md` pages, OpenAPI and a hosted MCP with OAuth mean an agent does not scrape HTML.
4. **Default in builders.** Lovable, v0, Bolt and Replit have first-party Resend guides.
5. **Official skills, plugin and CLI** reduce the odds of an agent using stale SDK shapes.
6. **Competitor response.** Cloudflare launched [Email Service "for agents"](https://blog.cloudflare.com/email-for-agents/) on 2026-04-16 ([HN, 2026-04-16](https://news.ycombinator.com/item?id=47792593)). HN reactions include spam worries ("this is going to be an absolute nightmare for spam") and price comparisons.

Implication for PostHog: matching Resend means a root `llms.txt` and `.md` pages for the email product, an OpenAPI spec for the send API, a skill that does "replace Resend with PostHog" (see [#522](https://github.com/Silthus/posthog/issues/522), section 4), and a path an agent can finish without a sales call. PostHog already has skills and MCP for templates; the send side is the gap.
